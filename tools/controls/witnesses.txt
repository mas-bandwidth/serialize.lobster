# read by tools/controls/controls.sh. Each row plants the OLD behaviour of one
# format 2.0 rule back into a staged copy of src/ and names the unit test that
# must then go red. Fields are TAB separated: witness, file, the count of lines
# the needle must match, the needle (an exact whole line), the line that
# replaces it, the test directory, and the test. A test marked expect-abort
# goes red when it no longer aborts.
#
# The read-side rules are witnessed by the per-rule controls in table.txt.
# One rule has no witness here because the API cannot observe it: a string
# read checks the claimed length against the remaining bytes BEFORE it
# allocates the payload; planting the allocation first changes only the
# memory used (measured by hand on 2026-10-22: 16 MB against 2.16 GB maximum
# resident for strings_claimed_length_before_allocation).

# test/uniform test that must then go red. U2's reject and object latch are
# corpus rules, witnessed by the reject-reason and object-latch-rejected
# controls in table.txt.
#

# the 2.1.0 behaviour (a write latch, a measure that is silent, a copy that
